## Como manter a assinatura

Preserve este arquivo e o crédito destacado no início do `README.md` em distribuições e versões derivadas.

Para identificação técnica dos commits locais, configure seu nome e e-mail Git **apenas neste repositório**:

```powershell
git config user.name "Marcos Paulo"
git config user.email "SEU_EMAIL_VERIFICADO_NO_GITHUB"
```

O e-mail acima é apenas um marcador: substitua-o pelo e-mail que você utiliza para atribuição de commits no GitHub (pode ser um endereço `noreply`).

No GitHub, acrescente a descrição do projeto em **Settings → General → Repository name / Description** e mantenha o link para o repositório oficial no README. Se desejar proteção formal adicional, avalie registro de software no INPI, no Brasil, e uma licença definida após revisar a origem e licenças de todas as contribuições.
